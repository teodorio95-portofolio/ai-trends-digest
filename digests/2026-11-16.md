- [HKUDS/AutoSwarm](https://github.com/HKUDS/AutoSwarm) — 2.546 stele (+64 azi) — Framework open-source (MIT, Python) de orchestrare multi-agent care selecteaza agentul potrivit per task, partajeaza context/memorie intre 12+ agenti (Codex, Claude Code, Cursor, GitHub Copilot CLI), ruleaza munca in paralel si sintetizeaza rezultatele; are si o aplicatie desktop (Windows/macOS) si o lucrare academica (arXiv:2610.33048) la baza. Relevant daca vrei sa combini mai multi coding agents pe acelasi task fara sa scrii propriul layer de coordonare.
- [Tencent/LoopForge](https://github.com/Tencent/LoopForge) (din nou) — 1.751 stele (+423 azi) — Platforma de orchestrare a coding agents (acoperita 15 nov. cu +33 azi) - azi creste de 12x mai rapid, cel mai mare salt zilnic de cand a aparut pe acest digest, cu un designer vizual de SOP-uri (roluri de agent, scripturi, porti de aprobare umana) peste Claude Code, Codex, Cursor CLI si altii.
- [ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui) (din nou) — 18.079 stele (+355 azi) — Protocol open-source (MIT, TypeScript) cu arhitectura bazata pe evenimente (~16 tipuri) care conecteaza un backend de agent la o interfata frontend: chat agentic in timp real, sincronizare de stare bidirectionala, UI generativa si colaborare human-in-the-loop, cu parteneriate LangChain, CrewAI, Microsoft Agent Framework, Google ADK, AWS Strands. Azi are cel mai mare ritm zilnic de cand a fost vazut prima data pe acest digest (exclus anterior pentru crestere minima).
