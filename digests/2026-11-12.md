## Nou: agents / harness / skills / plugins / MCP
- [herdrdev/herdr](https://github.com/herdrdev/herdr) — 50.393 stele (+2.213 saptamana asta) — Runtime terminal open-source (Rust, Apache-2.0, trecut prin Y Combinator) care ruleaza Claude Code, Codex, Cursor Agent CLI, OpenCode si altii nemodificati intr-un server de fundal, ca sesiunile sa continue dupa restart de masina, pierdere de retea sau laptop cu capacul inchis. Relevant pentru sesiuni lungi de agenti pe un repo de infra, fara sa pierzi contextul la fiecare reconectare.
- [shadcn/improve](https://github.com/shadcn/improve) — 11.071 stele (+361 azi) — Skill open-source (MIT) care foloseste cel mai capabil model doar pentru audit si plan (intelegere de cod, prioritizare, specificatie), iar executia o lasa pe modele mai ieftine, cu un pas de verificare care re-citeste fiecare locatie citata ca sa elimine fals-pozitivele. Impartire concreta costisitor/ieftin intre modele pe acelasi task de coding, nu un singur model scump pentru tot.
- [openai/codex-security](https://github.com/openai/codex-security) — 11.870 stele (+52 azi) — CLI si SDK TypeScript open-source (Apache-2.0) de la OpenAI care gaseste, valideaza si repara vulnerabilitati de securitate din linia de comanda, cu scanare in CI/CD, pre-commit hooks si output SARIF. Lansat in iulie, prima aparitie pe acest digest - alternativa directa la cloudflare/security-audit-skill (acoperit pe 8 nov.) pentru audit de securitate pe cod de infra.
- [experientiallabs/experiential](https://github.com/experientiallabs/experiential) — 16.600 stele (+589 azi) — Gateway open-source (Apache-2.0, Rust) fara comision pe tokeni, care unifica peste 1.000 de modele printr-un API compatibil OpenAI/Anthropic: chei proprii (BYOK), modele self-hosted si modele de marketplace, cu invatare din propriul trafic ca sa recomande modele mai ieftine. Relevant direct pentru a compara/schimba intre provideri fara sa rescrii integrarea de fiecare data.
- [Alishahryar1/free-claude-code](https://github.com/Alishahryar1/free-claude-code) — 68.741 stele (+636 azi) — Proxy open-source (MIT, Python/FastAPI) care ruteaza traficul Anthropic Messages API al Claude Code catre alti provideri compatibili (NVIDIA NIM, DeepSeek si altii) prin variabilele de mediu suportate oficial, ca sa ruleze CLI-ul fara cheie Anthropic. Util ca referinta pentru a conecta Claude Code la un endpoint propriu/local, nu neaparat ca sa inlocuiesti un abonament platit.
