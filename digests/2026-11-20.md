## Nou: agents / harness / skills / plugins / MCP
- [anomalyco/opencode](https://github.com/anomalyco/opencode) — 228.082 stele (+249 azi) — Agent de coding open-source (MIT, TypeScript) pentru terminal, desktop si IDE, cu doi agenti configurabili: Build (acces complet de editare) si Plan (doar citire, pentru analiza fara modificari); lansat in 2025, dar prima aparitie pe acest digest, cu peste 30.000 de fork-uri deja. Alternativa complet open-source la Claude Code/Codex, utila daca vrei control total asupra harness-ului fara sa depinzi de un abonament.
- [SWE-agent/mini-swe-agent](https://github.com/SWE-agent/mini-swe-agent) — 9.867 stele (+84 azi) — Agent de coding open-source (MIT, Python) in doar ~100 de linii, care rezolva issue-uri de GitHub sau ajuta direct in linia de comanda prin comenzi Bash, fara configurari complexe, si obtine totusi peste 74% pe SWE-bench Verified. Util ca referinta minimalista daca vrei sa intelegi bucla de baza a unui agent, in loc sa tratezi un harness ca o cutie neagra.
- [awslabs/cli-agent-orchestrator](https://github.com/awslabs/cli-agent-orchestrator) — 1.603 stele (+14 azi) — Platforma oficiala AWS Labs open-source (Apache-2.0, Python) de orchestrare multi-agent care ruleaza Claude Code, Codex, Kiro si alte CLI-uri de coding ca procese izolate in sesiuni tmux, cu un supervizor care delega task-uri in paralel sau secvential, memorie persistenta si server MCP propriu. Relevant direct pentru coordonarea mai multor agenti pe un repo de infra - exemplele oficiale includ fleet de robotica si deployment-uri Kubernetes.
- [Tracer-Cloud/opensre](https://github.com/Tracer-Cloud/opensre) — 13.214 stele (+38 azi) — Agent open-source (Apache-2.0, Python) de fiabilitate CI/CD care investigheaza automat un build picat, distinge intre o cauza de infrastructura si una de cod, si fie propune un fix pentru review, fie da pasi concreti de remediere, cu integrare in peste 60 de unelte (GitHub, GitLab, Slack, PagerDuty, Datadog, Grafana). Direct relevant pentru un pipeline GitLab CI propriu, ca prim pas de triaj automat inainte sa te uiti manual in loguri.
- [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl) — 204.433 stele (+825 azi) — Infrastructura open-source (AGPL-3.0 pe nucleu, SDK-uri MIT) care transforma orice site in continut curat pentru agenti: scraping, crawling, cautare web si peste 550 de provideri de date printr-un singur API, plus un binar local care ruleaza si ca server MCP. Proiect matur, prima aparitie pe acest digest - util ca sursa de date externe pentru un agent fara sa scrii propriul layer de scraping.
- [agentscope-ai/agentscope](https://github.com/agentscope-ai/agentscope) — 36.323 stele (+67 azi) — Framework open-source (Apache-2.0, Python) pentru construirea de agenti cu o bucla ReAct structurata, tool-uri de coding (shell, editare fisiere, cautare), planificare de task-uri si memorie, plus un backend multi-tenant cu UI web si executie izolata (Docker, Kubernetes, E2B). Alternativa la LangGraph/CrewAI daca vrei vizibilitate directa pe ce face agentul, nu doar un prompt rigid.

## GitHub Trending (restul relevant pentru AI)
- [Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec) — 75.291 stele (+95 azi) — Framework open-source (MIT, TypeScript) de spec-driven development pentru peste 30 de coding agents: inainte de implementare, agentul scrie propuneri/specificatii/design in fisiere Markdown intr-un folder dedicat, pe care le revizuiesti tu, nu doar istoricul de chat. Relevant daca vrei sa-ti scrii propriul harness minimal peste orice model, nu doar sa folosesti Claude Code ca atare.
- [bendlang/bend](https://github.com/bendlang/bend) — 25.626 stele (+98 azi) — Limbaj de programare open-source (Apache-2.0, compilator in Rust) care tinteste viteza C/CUDA si introduce un fisier `LAWS.bend` in care formalizezi reguli ("accesul la array nu trece niciodata de limita"); compilatorul cere o demonstratie matematica la fiecare schimbare, ca sa fie imposibil ca un agent sa comita cod care le violeaza. Idee interesanta de verificare formala impotriva gresalilor unui coding agent, desi necesita sa rescrii regulile intr-un limbaj nou, nu peste codul existent.
