- [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill) — 65.965 stele (+2.085 azi) — Skill open-source (MIT) de la Cloudflare care transforma un coding agent intr-un auditor de securitate printr-un audit structurat in sase faze (recunoastere, cautare de vulnerabilitati pe acoperire, validare de candidati, output structurat, verificare independenta a inregistrarilor, raportare neutra); instalare cu `npx skills add`. Exista de cateva saptamani (raportat anterior cu ~43.000 stele pe 24 oct.), dar azi are cel mai mare salt zilnic de pe tot acest digest - prima lui aparitie in corpul digestului. Relevant direct pentru un audit de securitate pe cod de infra/CI, nu doar pe aplicatii.
- [dsx-ai-factory/nvke](https://github.com/dsx-ai-factory/nvke) — 600 stele (+123 azi) — NVIDIA Kubernetes Engine (Apache 2.0): plan de management open-source care creeaza si opereaza clustere Kubernetes independente, fiecare cu control plane si etcd propriu, pe infrastructura bare-metal cu GPU NVIDIA, prin integrare cu Cluster API. Parte din platforma NVIDIA DSX OS pentru "AI factories" - relevant direct daca administrezi sau vei administra clustere Kubernetes cu GPU-uri NVIDIA alaturi de Terraform/OpenTofu.
- [ranxianglei/billion-context](https://github.com/ranxianglei/billion-context) — 4.689 stele (+191 azi) — Proxy de compresie de context (MIT) care se pune intre orice agent de coding (Claude Code, Codex, OpenCode, pi) si API-ul modelului, fara adaptor per-agent: comprima conversatia consumata in rezumate stratificate si reversibile, pastrand cache-ul de prefix intact, ca sa poti rula o sesiune unica de zile intregi cu o fereastra de doar ~100K tokeni si ~5x mai putini tokeni consumati. De comparat cu compactarea automata nativa din Claude Code/Codex daca sesiunile tale lungi pe un repo de infra consuma mult din resetarea de context.
