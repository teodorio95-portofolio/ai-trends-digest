## Nou: agents / harness / skills / plugins / MCP
- [langchain-ai/deepagents](https://github.com/langchain-ai/deepagents) — 30.814 stele (+46 azi) — Harness de agent "batteries-included", open-source (MIT), construit peste LangGraph: planificare cu `write_todos`, acces la filesystem si shell cu sandboxing, auto-summarizare a contextului cand conversatia creste, plus un CLI de coding agent inclus ("DeepAgents Code"), agnostic la model (Claude, OpenAI, Gemini). De comparat direct cu Claude Code daca vrei un strat open-source pe care sa-l poti extinde sau inlocui bucata cu bucata, nu doar configura.
- [MemPalace/mempalace](https://github.com/MemPalace/mempalace) — 60.167 stele (+258 azi) — Sistem de memorie pentru agenti, open-source si complet local (tehnica "memory palace"), cu 96,6% recall pe benchmark-ul LongMemEval fara niciun apel API extern. Nu e un proiect nou (a avut deja un val viral in aprilie 2026), dar e prima lui aparitie pe acest digest; de tratat cu precautie - comunitatea a semnalat ca metodologia de benchmark favorizeaza context care incape intr-o fereastra mica, nu memorie reala pe milioane de tokeni acumulati in timp, asa cum ar fi cazul intr-un proiect lung de infra.
- [lightpanda-io/browser](https://github.com/lightpanda-io/browser) — 38.544 stele (+626 azi) — Browser headless scris in Zig, optimizat special pentru workflow-uri de automatizare AI/agenti - mai usor si mai rapid decat un Chromium complet pentru scraping sau testare controlata de agent. De comparat cu ChromeDevTools/chrome-devtools-mcp (acoperit pe 28 oct.) daca vrei ceva mai usor de rulat intr-un pipeline GitLab CI decat un Chrome intreg, pentru agenti care verifica UI generat.
