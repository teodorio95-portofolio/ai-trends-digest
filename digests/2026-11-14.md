Relevant pentru a tine disciplina de proces peste Claude Code pe un repo de infra, nu doar sa generezi cod ad-hoc.
- [volcengine/OpenViking](https://github.com/volcengine/OpenViking) — 42.214 stele (+113 azi) — Baza de date de context "auto-evolutiva" pentru agenti (Rust, AGPLv3/Apache-2.0/MIT pe componente) de la Volcengine (ByteDance), care unifica memoria agentului, retrieval de cunostinte si skill-uri printr-un filesystem virtual (`viking://`) navigabil cu `ls`/`tree`/`read`/`write`/`grep`, cu cautare semantica scopata pe director, nu index plat. Alternativa structurata la memoria simpla tip note/markdown pentru sesiuni lungi.
- [headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom) — 79.614 stele (+120 azi) — Unealta open-source (Apache-2.0, Rust, SDK-uri Python/TypeScript) care comprima output-uri de tool-uri, loguri, fisiere si chunk-uri RAG inainte sa ajunga la model, raportat 20% mai putini tokeni pentru coding agents si 60-95% mai putini pentru JSON; disponibila ca librarie, proxy sau server MCP. De comparat cu ranxianglei/billion-context (acoperit 8-9 nov.) pentru acelasi tip de problema de consum de context pe sesiuni lungi.
- [google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model) — 18.697 stele (+5.560 saptamana asta) — Plugin open-source (Apache-2.0, Python) de la Google pentru un workflow colaborativ de design: componenta "elephant" tine contextul proiectului si redacteaza specificatii, componenta "goldfish" le revizuieste cu o perspectiva proaspata ca sa gaseasca prezumtii si unghiuri moarte, inainte sa decizi arhitectura si sa implementezi. Mentionat ca unealta "de urmarit" intr-un articol Medium pe 12 nov., azi prima aparitie directa pe GitHub Trending.
