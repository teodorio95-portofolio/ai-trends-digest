## Nou: agents / harness / skills / plugins / MCP
- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) — 128.529 stele (+626 azi) — Transforma un codebase (plus documentatie, scheme SQL, config-uri, PDF-uri) intr-un graf de cunostinte interogabil, prin parsare AST locala si determinista (tree-sitter, fara LLM), pentru aproximativ 40 de limbaje; ca skill, `/graphify .` genereaza o vizualizare HTML, un raport markdown si un fisier JSON interogabil. Confirmat si de un articol Medium din aceeasi zi (vezi sectiunea Medium) care arata un apel de "explain" la 628 tokeni in loc de 13.659 - util direct cand Claude Code face grep brut pe un repo mare de infra.
- [diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute) — 78.208 stele (+429 azi) — Gateway AI gratuit (MIT) care unifica 375 de provideri sub un singur endpoint, cu 20 de strategii de rutare, fallback automat intre niveluri de provider si compresie de tokeni ("RTK + Caveman") care promite 15-95% economie; compatibil cu peste 37 de unelte, inclusiv Claude Code, Cursor, Aider. De comparat cu OpenRouter direct daca vrei sa combini mai multe conturi gratuite intr-un singur buget.
- [earendil-works/pi](https://github.com/earendil-works/pi) — 116.217 stele (+191 azi) — Toolkit de agent minimalist si extensibil: API unificat pentru OpenAI/Anthropic/Google, runtime de agent cu tool calling, si un CLI interactiv de coding agent, fara sub-agenti sau plan mode incluse din oficiu ("ii ceri agentului sa construiasca ce-ti lipseste"). Alternativa mai usoara de testat alaturi de Claude Code daca vrei control total peste ce ruleaza, nu un harness deja incarcat cu functii.
- [superdesigndev/treg](https://github.com/superdesigndev/treg) — 5.762 stele (+68 azi) — Registru de tip "OpenRouter pentru unelte de agent": agentii acceseaza mii de API-uri externe (analiza de backlink-uri, date social media, imbogatire de date despre persoane etc.) printr-un singur token si URL, cu autentificarea injectata server-side, fara ca agentul sa vada vreodata cheile reale. Include CLI si plugin de Claude Code; relevant daca vrei sa dai agentilor acces controlat la unelte externe fara sa gestionezi zeci de chei API separate.
- [mozilla-ai/otari](https://github.com/mozilla-ai/otari) — 669 stele (+39 azi) — Gateway LLM compatibil OpenAI/Anthropic, sustinut de Mozilla.ai, care centralizeaza accesul la peste 40 de provideri sub un singur endpoint, cu chei revocabile cu scop granular (user/workspace/model) si limite de buget verificate inainte de trimiterea request-ului, nu doar dupa. Mic azi, dar relevant pentru cineva care vrea control de cost self-hosted peste mai multe provideri, nu doar un wrapper simplu.
