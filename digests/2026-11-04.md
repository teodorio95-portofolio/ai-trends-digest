## Nou: agents / harness / skills / plugins / MCP
- [deepseek-ai/dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype) — 17.300 stele (+nou) — Prototip de cercetare (MIT, publicat 31 oct.) al unui "super-agent" proactiv scopat pe un singur repo GitHub: un router global primeste cereri (GitHub, opțional Feishu), distribuie munca la workeri paraleli cu sesiune/context propriu, iar rezultatul (de ex. un PR) se raporteaza inapoi in conversatia originala. DeepSeek raporteaza un timp median de finalizare de 12,4 minute fata de 29,5 minute pentru o sesiune unica traditionala - un exemplu concret de arhitectura multi-agent peste un harness (DeepSeek Harness), de comparat cu echipele de agenti din Claude Code.
- [Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec) — 73.847 stele (+117 azi) — Framework open-source (MIT) pentru "spec-driven development": adauga un strat de specificatie (change folders cu propuneri, task-uri si spec-delta) peste orice agent de coding, ca sa cazi de acord cu agentul pe ce construiesti inainte sa scrie cod, nu doar in istoricul de chat. Functioneaza cu 25+ asistenti (Claude Code, Copilot, Cursor, OpenCode) prin slash commands sau AGENTS.md - util daca vrei o disciplina de specificatie mai usoara decat un proces formal, pe un repo Terraform/Kubernetes.
- [blader/humanizer](https://github.com/blader/humanizer) — 64.494 stele (+407 azi) — Skill Markdown (MIT) pentru Claude Code si OpenCode care detecteaza si rescrie 29 de tipare de "scris de AI" (din ghidul Wikipedia Signs of AI writing), cu calibrare optionala pe vocea proprie si un al doilea pas de audit. Util pentru documentatie tehnica sau descrieri de PR generate de agent care trebuie sa sune ca scrise de tine, nu de un LLM.
- [tashfeenahmed/freellmapi](https://github.com/tashfeenahmed/freellmapi) — 47.154 stele (+688 azi) — Gateway open-source (MIT) care agrega tier-urile gratuite de la ~30 de provideri (Google, Groq, Cerebras, Mistral, OpenRouter, Cloudflare, Z.ai etc.) in spatele unui singur endpoint compatibil OpenAI, cu router care alege modelul disponibil si fallback automat cand un provider e limitat. Direct relevant pentru "cheaper ways to run good models" - o singura integrare in loc sa gestionezi manual mai multe chei gratuite.
- [mattpocock/sandcastle](https://github.com/mattpocock/sandcastle) — 8.823 stele (+31 azi) — Libraria TypeScript (Matt Pocock, pe Effect) care orchestreaza agenti de coding (Claude Code, Codex, Cursor, OpenCode, Copilot) in sandbox-uri izolate (Docker/Podman/Vercel) printr-un singur `sandcastle.run()`, pe branch-uri configurabile, cu merge automat al commit-urilor rezultate inapoi in repo. Alternativa mai usoara la ParadevAI/Paradev sau worktrunk pentru paralelizarea agentilor fara sa te calci pe picioare pe fisiere.
