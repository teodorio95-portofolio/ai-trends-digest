## Nou: agents / harness / skills / plugins / MCP

- [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach) — 100.733 stele (+426 azi) — CLI/skill open-source care da unui agent (Claude Code, Cursor, OpenClaw) acces gratuit la internet prin backend-uri existente (Jina Reader, yt-dlp, Exa, gh CLI, feedparser) pentru Twitter/X, Reddit, YouTube, GitHub si altele, fara chei API separate per platforma; token-urile raman local in `~/.agent-reach/config.yaml`. Util daca vrei ca Claude Code sa citeasca direct un thread sau un issue extern fara sa scrii propriul wrapper MCP.
