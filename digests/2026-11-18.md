## Nou: agents / harness / skills / plugins / MCP
- [obra/superpowers](https://github.com/obra/superpowers) — 319.484 stele (+1.917 azi) — Framework open-source (MIT, JavaScript) de la Jesse Vincent: 14 skill-uri compozabile, cu peste 3,1 milioane de instalari, care impun unui coding agent (Claude Code, Cursor, Codex, OpenCode, Gemini CLI) o metodologie disciplinata - test-driven development si workflow-uri cu subagenti - ca sa nu "sprinteze" direct la cod fara teste pe task-uri lungi. Relevant ca referinta de disciplina de proces, similar cu EveryInc/compound-engineering-plugin (acoperit 14 nov.), dar cu adoptie mult mai mare.
- [affaan-m/ECC](https://github.com/affaan-m/ECC) (Everything Claude Code) — 305.705 stele (+883 azi) — Strat de plugin open-source (MIT, TypeScript) peste Claude Code, Codex si Cursor: 72 de agenti specializati, 327 de skill-uri si 98 de comenzi, plus hooks si reguli, pentru coordonare de workflow (plan -> testare -> implementare -> review -> verificare) fara sa rescrii disciplina asta in fiecare prompt. Alternativa cu adoptie la fel de masiva ca obra/superpowers de mai sus, pe aceeasi problema de disciplina peste un coding agent.
- [stablyai/orca](https://github.com/stablyai/orca) — 128.050 stele (+1.066 azi) — Platforma open-source (MIT, TypeScript) de orchestrare a unei flote de coding agents (Claude Code, Codex, OpenCode, Pi) cu propriul abonament, fiecare in propriul git worktree, cu interfata desktop/mobil/remote si un coordinator care imparte un task mare intre agenti de lucru si sintetizeaza rezultatele. Relevant direct daca vrei sa rulezi mai multe sesiuni Claude Code in paralel pe un repo de infra, cu vizibilitate unificata.
- [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) — 149.749 stele (+649 azi) — Skill/server MCP open-source (MIT/Apache-2.0, Python) care transforma un repo (cod, documentatie, scheme SQL, PDF-uri) intr-un graf de cunostinte interogabil, cu parsare locala AST (tree-sitter, fara LLM) pentru cod si imbogatire semantica doar pentru continut non-cod. Agentul interogheaza graful in loc sa citeasca fisiere intregi, cu mai putini tokeni consumati - util pe un repo mare de infra unde Claude Code trebuie sa inteleaga relatii intre fisiere.
- [cursor/plugins](https://github.com/cursor/plugins) — 16.959 stele (+201 azi) — Specificatie si marketplace oficial (MIT) de plugin-uri Cursor, cu peste 100 de plugin-uri organizate pe categorii (unelte de dezvoltator, productivitate, integrari), fiecare cu manifest propriu, skill-uri, reguli si definitii de server MCP. Echivalentul direct al plugin-urilor/skill-urilor Claude Code, dar pe ecosistemul Cursor - util ca referinta daca echipa foloseste ambele unelte.
- [ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui) (din nou) — 20.107 stele (+1.445 azi) — Protocol de evenimente pentru conectarea unui backend de agent la o interfata frontend (acoperit 16 nov. cu +355 azi) - azi are de peste 4 ori ritmul de atunci, cel mai mare salt zilnic de cand a aparut pe acest digest.
