## Nou: agents / harness / skills / plugins / MCP
- [GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src) — 3.414 stele (+739 azi) — Sursa oficiala Chrome pentru un set de skill-uri care injecteaza in orice coding agent compatibil cu Skills (Claude Code, Gemini CLI, Copilot) bune practici curate si date de compatibilitate browser pentru peste 100 de cazuri de utilizare web, ca agentul sa nu mai scrie cod invechit din datele lui de antrenament. Relevant daca agentul tau atinge si cod frontend alaturi de infra, nu doar YAML/Terraform.
- [QwenLM/qwen-code](https://github.com/QwenLM/qwen-code) — 29.926 stele (+151 azi) — Agent CLI open-source de la Alibaba Tongyi Lab, optimizat pentru Qwen3-Coder, cu auto-memorie, auto-skills, subagenti si suport MCP, compatibil si cu API-uri OpenAI/Anthropic/Gemini, nu doar Qwen. Cont gratuit prin Qwen OAuth cu 1.000 de cereri/zi - alternativa gratuita directa la Claude Code pentru task-uri unde nu vrei sa consumi propriul abonament.
- [NVIDIA/SkillSpector](https://github.com/NVIDIA/skillspector) — 25.732 stele (+297 azi) — Scanner de securitate open-source bazat doar pe analiza statica (nu ruleaza skill-ul) care verifica un skill de agent (Claude Code, Codex CLI, Gemini CLI) pe 64 de tipare de vulnerabilitate in 16 categorii inainte de instalare, cu scor de risc 0-100 si output SARIF. NVIDIA raporteaza ca 26% din skill-urile publice au vulnerabilitati si 5% au intentie probabil malitioasa - de rulat pe orice skill extern inainte sa-l pui langa un repo de productie.
- [CopilotKit/OpenBot](https://github.com/CopilotKit/OpenBot) — 11.761 stele (+298 azi) — Template open-source (MIT) de "AI coworkers" self-hosted: fiecare agent primeste propriul computer izolat (browser, fisiere, terminal), cu un gateway care verifica fiecare actiune contra unei politici si o inregistreaza intr-un audit log, conectat prin protocolul AG-UI la LangGraph/CrewAI/Pydantic AI. Lansat pe 1 nov., relevant pentru a rula agenti cu acces la browser/fisiere fara sa le dai acces direct la propria masina.
