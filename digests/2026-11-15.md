## Nou: agents / harness / skills / plugins / MCP
- [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) — 56.405 stele (+664 azi) — Server MCP oficial (Apache-2.0, TypeScript) al echipei Chrome DevTools, care da unui coding agent (Claude Code, Cursor, Copilot, Gemini CLI) control si inspectie directa pe un Chrome real: trasare de performanta, analiza de retea, capturi de ecran, consola si actiuni automate cu asteptare automata a rezultatului. Exista de cateva luni, dar prima aparitie pe acest digest - relevant daca agentul tau atinge si front-end/browser alaturi de infra de backend.
- [Tencent/LoopForge](https://github.com/Tencent/LoopForge) — 982 stele (+33 azi) — Platforma open-source (MIT, Go) de la Tencent care orchestreaza coding agents (Claude Code, Codex, CodeBuddy) prin SOP-uri (Standard Operating Procedures) ce combina pasi de agent, scripturi si porti de aprobare umana, cu sandbox-uri Docker si integrare directa cu fluxuri de PR/MR. Relevant pentru un pipeline de livrare auto-hostat peste coding agents, nu doar sesiuni ad-hoc in terminal.
- [andrewyng/openworker](https://github.com/andrewyng/openworker) — 19.237 stele (+100 azi) — Aplicatie desktop si Harness SDK open-source (MIT, Python/Rust/TypeScript) de la Andrew Ng: agentul ruleaza local ("totul traieste pe masina ta"), cu porti de aprobare, audit trail al actiunilor si suport pentru peste 25 de conectori prin MCP pentru research, code review si automatizari. Relevant ca alternativa locala, cu accent pe guvernanta, la un harness cloud.
- [elementalsouls/Claude-BugHunter](https://github.com/elementalsouls/Claude-BugHunter) — 5.855 stele (+124 azi) — Bundle open-source (MIT/CC BY 4.0, Python) de 83 de skill-uri si 15 slash commands pentru Claude Code, axat pe bug hunting si red-team autorizat: 681 de tipare de vulnerabilitate din rapoarte HackerOne publice, cu porti explicite de validare a autorizarii inainte de orice submisie. Util ca referinta de skill-uri de securitate, dar de folosit doar in angajamente autorizate.
- [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) — 120.146 stele (+227 azi) — Unealta open-source (Apache-2.0/MIT, TypeScript) de reducere de tokeni pentru peste 30 de coding agents (Claude Code, Codex, Gemini CLI): comprima loguri/JSON/CSV, alege automat modelul potrivit per task si reutilizeaza blocuri de cod, citata deja de Adobe Research si testata de JetBrains. Crestere virala verificata (nr. 1 pe Hacker News in aprilie 2026) - de comparat cu headroomlabs-ai/headroom (acoperit 14 nov.) pe aceeasi problema de cost de tokeni.
- [alibaba/open-code-review](https://github.com/alibaba/open-code-review) (din nou) — 51.524 stele (+893 azi) — Unealta de code review AI de la Alibaba (acoperita 14 nov. cu +215 azi) - azi creste de peste patru ori mai rapid, cel mai mare ritm zilnic de cand a aparut pe acest digest, si a obtinut recent statutul OpenSSF Gold pentru bune practici.
