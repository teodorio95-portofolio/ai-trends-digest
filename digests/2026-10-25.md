## Nou: agents / harness / skills / plugins / MCP
- [anthropics/sandbox-runtime](https://github.com/anthropics/sandbox-runtime) — 6.523 stele (+650 azi) — Unealta oficiala Anthropic de sandboxing la nivel de OS (sandbox-exec pe macOS, bubblewrap pe Linux), fara container, folosita ca sa limitezi ce poate accesa un server MCP sau un agent. Alternativa mai usoara decat NVIDIA/OpenShell (cluster K3s complet) cand ai nevoie doar sa izolezi un proces, nu un shell persistent intreg.
- [aws/agent-toolkit-for-aws](https://github.com/aws/agent-toolkit-for-aws) — 3.184 stele (+13 azi) — Suita oficiala AWS cu peste 40 de skill-uri (CloudFormation, serverless, containere, date) plus un MCP Server AWS gestionat cu guardrails IAM si observabilitate CloudWatch/CloudTrail, si plugin-uri de instalare rapida pentru Claude Code/Codex. Daca ai workload-uri si pe AWS langa Terraform/OpenTofu, e un punct de plecare oficial mai sigur decat un server MCP neoficial.
- [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) — 102.869 stele (+278 azi) — Plugin care capteaza tot ce face un agent intr-o sesiune (tool calls, fisiere modificate, decizii), le comprima cu AI si le reinjecteaza selectiv in sesiunile viitoare, pentru Claude Code, Codex, OpenCode si altele. Rezolva exact problema "repeti aceleasi explicatii agentului in fiecare sesiune noua" pe un proiect Terraform/Kubernetes de lunga durata.
- [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) — 53.491 stele (+329 azi) — Sistem de memorie pe termen lung pentru agenti (cunostinte, experiente, opinii, observatii separate), cu workflow retain-recall-reflect si 91,4% pe benchmark-ul LongMemEval, integrabil ca layer de memorie in CrewAI, LangGraph sau Claude Code. De comparat cu claude-mem de mai sus daca vrei o memorie structurata, nu doar un rezumat comprimat de sesiune.
- [Nutlope/hallmark](https://github.com/Nutlope/hallmark) — 32.361 stele (+455 azi) — Skill de design pentru Claude Code, Cursor si Codex, cu 65 de verificari anti-"AI slop" (contrast, tipografie, structura paginii) inainte sa livreze UI generat de agent. Util daca Claude Code iti genereaza si dashboard-uri interne/UI de admin pentru infra, nu doar cod backend.
- [makecindy/cindy](https://github.com/makecindy/cindy) — 4.203 stele (+477 azi) — Client desktop/mobil open-source care combina mai multe harness-uri (Claude Code, Codex) si modele intr-un singur agent ce lucreaza pe fisierele si aplicatiile tale locale, cu memorie si skill-uri continue intre harness-uri. De testat ca strat unificator peste Claude Code si Codex, fara sa platesti doua abonamente separate.
