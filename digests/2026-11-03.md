## Nou: agents / harness / skills / plugins / MCP
- [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop) — 10.461 stele (+2.275 azi) — CLI open-source in Rust (Vercel Labs) care da unui agent control de "computer use" asupra desktop-ului prin accessibility tree-ul sistemului de operare, nu prin screenshot-uri sau simulare de click-uri pe pixeli, cu output JSON structurat si refs deterministe per element. Relevant daca vrei sa automatizezi aplicatii desktop (console de infra fara API, unelte legacy) direct dintr-un agent Claude Code/Codex, fara recunoastere vizuala fragila.
- [JustVugg/colibri](https://github.com/JustVugg/colibri) — 46.708 stele (+675 azi) — Motor de inferenta intr-un singur fisier C, fara dependinte (zero BLAS, zero Python la runtime, GPU opțional), care ruleaza modele MoE de talie frontier (GLM-5.2 744B, Kimi K3 2.8T, DeepSeek V4 Flash 284B, Qwen3.6, OLMoE) pe hardware de consum prin streaming de experti direct de pe disc - GLM-5.2 cu doar ~25GB RAM. Cel mai concret exemplu de pe acest digest pentru "ruleaza un model frontier fara cloud si fara GPU dedicat", de testat ca alternativa radicala la Ollama pentru modele foarte mari.
- [cheaper-inference/OmniRoute](https://github.com/cheaper-inference/OmniRoute) — 84.027 stele (+402 azi) — Gateway AI open-source (MIT, TypeScript) cu un singur endpoint compatibil OpenAI care ruteaza cereri catre 375+ provideri (150+ gratuiti), cu fallback automat intre Claude/GPT/Gemini si compresie de tokeni raportata intre 15-95% (medie ~89%), plus integrare directa cu Claude Code, Cursor, Cline, Copilot. Direct relevant pentru "cheaper ways to run good models" - un singur proxy intre agentul tau si toate API-urile platite/gratuite pe care le folosesti.
- [vercel-labs/skills](https://github.com/vercel-labs/skills) — 37.834 stele (+244 azi) — CLI open-source pentru ecosistemul de Agent Skills: instaleaza, cauta si ruleaza skill-uri SKILL.md pe 51+ agenti de coding (Claude Code, Codex, Cursor, OpenCode etc.) cu o singura comanda (`npx skills add`, `npx skills find`, `npx skills use --agent`). Util ca "package manager" neutru pentru skill-uri, fara sa depinzi de un marketplace legat de un singur harness.
- [mksglu/context-mode](https://github.com/mksglu/context-mode) — 33.307 stele (+151 azi) — Plugin local care pune output-ul brut al tool-urilor (fisiere mari, snapshot-uri Playwright, liste de issue-uri) intr-un sandbox in afara ferestrei de context a agentului, cu pana la 98% reducere de tokeni consumati de operatii de rutina, pe 15+ platforme (Claude Code, Cursor, Copilot). Relevant daca sesiunile tale de Claude Code pe un repo mare de infra consuma context rapid doar din citiri de fisiere si output de shell.
- [max-sixty/worktrunk](https://github.com/max-sixty/worktrunk) — 10.123 stele (+77 azi) — CLI in Rust pentru gestionarea worktree-urilor Git, facut explicit pentru a rula 5-10+ agenti de coding in paralel (Claude Code, Codex), fiecare in propriul working directory, cu comenzi simplificate (`wt switch`, `wt remove`, `wt list`) si hook-uri de proiect pentru automatizari la create/pre-merge/post-merge. Util direct pe un repo Terraform/Kubernetes daca vrei sa paralelizezi mai multi agenti fara sa te calci pe picioare pe fisiere - alternativa mai usoara la ParadevAI/Paradev (acoperit pe 29 oct.).
