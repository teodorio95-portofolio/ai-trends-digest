## Nou: agents / harness / skills / plugins / MCP
- [affaan-m/ECC](https://github.com/affaan-m/ECC) — 280.926 stele (+1.057 azi) — "Agent Harness Operating System" cu 71 de agenti specializati si 311 skill-uri reutilizabile, care forteaza workflow-uri deterministe (TDD inainte de implementare, code review cu context curat) plus scanarea de securitate AgentShield impotriva prompt-injection, peste Claude Code, Codex si Cursor. De comparat cu obra/superpowers daca vrei acelasi tip de disciplina de proces peste infra proprie.
- [obra/superpowers](https://github.com/obra/superpowers) — 300.392 stele (+973 azi) — Metodologie completa de dezvoltare software pentru coding agents, construita din skill-uri compozabile: brainstorming, design, TDD si code review inainte ca agentul sa scrie cod efectiv, cu izolare prin git worktree si subagenti paraleli. Util daca Claude Code iti "sare" direct la implementare fara sa gandeasca planul.
- [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) (din nou) — 39.872 stele (+1.552 azi) — Director oficial Anthropic de plugin-uri Claude Code verificate; cresterea de azi e de peste 8x fata de ultima mentiune (+181/zi pe 15 oct.). Punct de plecare mai sigur decat liste comunitare inainte sa scrii un plugin propriu pentru infra.
- [xerj-org/xerj](https://github.com/xerj-org/xerj) — 6.434 stele (+1.647 azi) — Motor de cautare local care indexeaza automat cod, documentatie, loguri si PDF-uri fara configurare de schema, cu 2,7x mai putine tokeni de output fata de grep pe acelasi rate de rezolvare (si pana la 5x in scenarii reale, conform autorilor). De testat pentru cautare in cod/documentatie/loguri intr-un repo mare de infra, inainte sa lasi Claude Code sa faca grep brut.
- [lightseekorg/tokenspeed](https://github.com/lightseekorg/tokenspeed) — 2.644 stele (+374 azi) — Motor de inferenta LLM open-source optimizat pentru workload-uri agentice, cu control plane in C++ (scheduling tip masina cu stari finite) si execution plane in Python, tintind performanta de tip TensorRT-LLM cu usurinta de utilizare de tip vLLM. De testat local alaturi de Ollama/vLLM ca alternativa gratuita la API platit.
- [Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec) — 72.128 stele (+113 azi) — Framework usor de "spec-driven development": cerintele, specificatiile si planurile de implementare se scriu in Markdown simplu, ca om si agent sa cada de acord asupra a ce se construieste inainte de a scrie cod, compatibil cu peste 30 de unelte AI. Util ca sa nu lasi Claude Code sa inceapa direct implementarea pe un task de infra neclar.
- [apache/maka](https://github.com/apache/maka) — 5.808 stele (+53 azi) — Workspace de agenti in incubare la Apache, cu log append-only de evenimente pentru fiecare mesaj de model, executie de tool si decizie de permisiune, date locale fara sincronizare in cloud, accesibil din desktop, CLI si pentru evaluare. Relevant pentru guvernanta si trasabilitate cand mai multi agenti opereaza pe infra de productie.
- [abcwyc/pi-agent-desktop](https://github.com/abcwyc/pi-agent-desktop) — 786 stele (+269 azi) — Aplicatie desktop standalone pentru macOS/Windows care aduce un coding agent intr-o interfata nativa, fara configurare de terminal, cu sesiuni de chat in timp real si task-uri programate. Util daca vrei o interfata grafica fara sa configurezi terminalul pe fiecare masina.
