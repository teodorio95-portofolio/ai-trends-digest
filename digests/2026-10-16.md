- [affaan-m/ECC](https://github.com/affaan-m/ECC) — 280.913 stele (+1.057 azi) — Sistem de optimizare a harness-ului de agenti cu 71 de agenti specializati si 311 skill-uri reutilizabile (TDD, code review cu context curat, scanare de securitate AgentShield pentru prompt-injection si hook-uri), nativ pe Claude Code, cu adaptoare pentru Codex, Qoder, Cursor, OpenCode, GitHub Copilot si altele. - [obra/superpowers](https://github.com/obra/superpowers) — 300.384 stele (+973 azi) — Framework de skill-uri agentice care forteaza un proces disciplinat (brainstorming, design, TDD, code review) inainte ca agentul sa scrie cod, cu subagenti care pot lucra autonom ore in sir pe un plan pre-aprobat. Util daca Claude Code iti "sare" direct la implementare fara sa gandeasca planul.
- [anomalyco/opencode](https://github.com/anomalyco/opencode) — 214.176 stele (+401 azi) — Agent de coding open-source cu doi agenti incorporati: unul cu acces complet ("build") si unul doar-citire pentru explorare ("plan"), disponibil prin CLI si aplicatie desktop. Alternativa gratuita/open-source la Claude Code sau Codex daca vrei control complet pe stack.
- [cursor/plugins](https://github.com/cursor/plugins) — 11.781 stele (+214 azi) — Specificatia oficiala de plugin-uri pentru Cursor, cu agent skills, reguli si definitii de MCP server pentru peste 100 de servicii integrate. - [abcwyc/pi-agent-desktop](https://github.com/abcwyc/pi-agent-desktop) — 785 stele (+269 azi) — Aplicatie desktop standalone pentru macOS/Windows care aduce agentul de coding intr-o interfata unificata, cu navigare de sesiuni intre proiecte, conversatii ramificate, vizibilitate asupra costurilor si task-uri programate. Util daca vrei o interfata grafica fara sa configurezi terminalul pe fiecare masina.
- [xerj-org/xerj](https://github.com/xerj-org/xerj) — 6.427 stele (+1.647 azi) — Motor de cautare local care indexeaza automat cod, documentatie, loguri si PDF-uri fara configurare de schema, cu 2,7x mai putine tokeni de output fata de grep la acelasi rate de rezolvare. De testat pentru cautare in cod/documentatie/loguri intr-un repo mare de infra, inainte sa lasi Claude Code sa faca grep brut.
- [lightseekorg/tokenspeed](https://github.com/lightseekorg/tokenspeed) — 2.643 stele (+374 azi) — Motor de inferenta LLM de mare performanta pentru workload-uri agentice, cu control plane in C++ (scheduling ca o masina cu stari finite) si execution plane in Python pentru iteratie rapida. De testat local alaturi de vLLM/Ollama ca alternativa gratuita la API platit.
- [BuilderIO/agent-native](https://github.com/BuilderIO/agent-native) — 7.380 stele (+107 azi) — Framework TypeScript de la Builder.io care defineste o capabilitate o singura data ca "actiune": agentul o foloseste ca tool, UI-ul o apeleaza direct din cod, cu stare si date partajate intre agent si interfata. Relevant daca vrei dashboard-uri de aprobare/inspectie peste agenti de infra, nu doar un terminal.
